# Оценка цены бриллианта

Учебный ML-проект: прогноз цены бриллианта в долларах
по весу, огранке, цвету, чистоте, размерам и пропорциям. Исследование и обучение —
в [Diamonds.ipynb](Diamonds.ipynb), интерактивная форма — в [app.py](app.py).

## Эксперимент и результаты

После удаления строк без цены и полных дубликатов остаются 53 772 записи.
Одинаковые наборы входных признаков объединяются в группы, которые не
пересекаются между train/test и фолдами кросс-валидации. На тест отложено
10 763 записи, seed — 42. Пропуски заполняются внутри pipeline только
по обучающей части каждого фолда.

Выбор модели — по среднему MAE на пяти фолдах обучающей выборки.
MAE отражает среднюю абсолютную ошибку в долларах;
RMSE дополнительно чувствителен к крупным промахам.

| Модель | MAE на CV, $ | MAE на тесте, $ | RMSE на тесте, $ | R² на тесте |
|---|---:|---:|---:|---:|
| Ridge | 742.71 | 737.41 | 1123.55 | 0.919 |
| Decision tree | 340.66 | 333.01 | 637.67 | 0.974 |
| Boosting (15 leaves) | 296.12 | 294.22 | 553.30 | 0.980 |
| Boosting (31 leaves) | **283.32** | **281.36** | **540.71** | **0.981** |

Проверены четыре заранее заданных варианта, а не исчерпывающий поиск параметров.
Точные метрики и SHA-256 данных — в [artifacts/benchmark.json](artifacts/benchmark.json).

## EDA и важность признаков

В EDA показаны пропуски, некорректные числовые значения и несколько примеров
подозрительно больших размеров. Положительные аномальные размеры сохраняются
без изменений: точные исправления по исходному файлу установить нельзя.
Показ примеров с размером больше 20 мм не влияет на обучение.
Фильтрации аномалий и отдельного анализа ошибок на них нет.
Нулевые и отрицательные числовые значения, как и прежде, переводятся в пропуски.

Важность признаков оценивается через прирост MAE при перемешивании на полном
тесте, 10 повторов. Масса и размеры проверяются также совместно из-за их
сильной связи. Показаны средние приросты ошибки, разброс и корреляции по train.
Это зависимость конкретной модели от информации, а не причинное влияние
на цену. Величины важности нельзя складывать и считать долями цены.

Самый важный отдельный признак для этой модели — `carat`: его перемешивание
увеличивает MAE в среднем на $2 185.11. Совместное перемешивание массы и
размеров увеличивает MAE на $4 107.02. Эти приросты ошибки относятся к
искусственному нарушению информации в признаках, а не к изменению цены
при увеличении веса или размера камня.

## Структура кода

- [Diamonds.ipynb](Diamonds.ipynb) — подготовка данных, исследование, обучение,
  сравнение моделей и сохранение результатов.
- [app.py](app.py) — интерфейс Streamlit и прогноз по сохранённой модели.
- [diamonds.py](diamonds.py) — общий модуль настроек: пути к данным и артефактам,
  числовые признаки, допустимые категории и полный список входных столбцов.
  Он не обучает модель; ноутбук и приложение импортируют одинаковые настройки.

## Запуск

Откройте терминал PowerShell в корне проекта. Для нового окружения
рекомендуется Python 3.11. Существующую `.venv` с Python 3.13 можно использовать
после установки зависимостей; если она уже создана, пропустите первую команду.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-notebook.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Для одного приложения достаточно установить [requirements.txt](requirements.txt).
Готовая модель — [artifacts/model.joblib](artifacts/model.joblib): CSV и повторное
обучение для запуска формы не требуются. В форме нужны все девять признаков.
Вкладка **Эксперименты** показывает результаты сохранённого эксперимента.

## Запуск ноутбука в VS Code

1. Установите расширения **Python** и **Jupyter** от Microsoft.
2. Откройте папку проекта, затем [Diamonds.ipynb](Diamonds.ipynb).
3. Установите зависимости командой из раздела выше.
4. Справа сверху выберите **Select Kernel → Python Environments** → Python
   из `.venv\Scripts\python.exe` именно этой папки.
5. Нажмите **Restart Kernel**, затем **Run All**. Ячейки зависят от предыдущих.

Если возникает `ModuleNotFoundError: No module named 'matplotlib'`, зависимости
не установлены в Python, выбранный ядром. Проверьте его путь в отдельной ячейке:

```python
import sys
print(sys.executable)
```

Путь должен указывать на `.venv\Scripts\python.exe` проекта. После установки
пакетов перезапустите ядро и выполните всё с начала. Ошибки
`GroupKFold is not defined` и `plt is not defined` могут быть следствием
ошибки или пропуска первой ячейки импорта.

Альтернативный запуск в браузере:

```powershell
.\.venv\Scripts\python.exe -m jupyterlab Diamonds.ipynb
```

Последняя ячейка сохраняет модель и отчёт. После повторного обучения
Streamlit перечитает модель при следующем взаимодействии со страницей.

## Данные

Источник, указанный автором проекта:
[Diamonds — Ayesha Seherr, Kaggle](https://www.kaggle.com/datasets/ayeshaseherr/diamonds).
Для повторения обучения скачайте датасет, распакуйте и положите CSV
в `data/diamonds.csv`. CSV есть в локальной рабочей копии, но исключён из Git.
Условия использования данных следует смотреть в разделе License источника;
копия данных в этом репозитории не распространяется.

Локальная версия содержит десятичные запятые, пропуски и значения `isntKnown`.
История преобразований после скачивания не зафиксирована, поэтому совпадение
метрик с заново скачанным файлом не гарантируется. Для точного повторения
нужен тот же файл, что использовался в эксперименте: 53 940 строк, SHA-256:

```text
d2d4cf7f8ef3c1a6bd11d6cc354be90ccc929bcc44ae201b70ecc17c6ed9ead5
```

Ожидаемые столбцы: `carat`, `cut`, `color`, `clarity`, `depth`, `table`,
`price`, `x`, `y`, `z`. ID не используется. Чтение поддерживает десятичные
точки и запятые, а также автоматическое определение разделителя.

## Ограничения и дальнейшая работа

- Это оценка на исторических данных, а не актуальная рыночная котировка.
- Для цен выше $10 000 MAE составляет $932.64. Общая средняя метрика скрывает
  различия между ценовыми диапазонами и не задаёт интервал отдельного прогноза.
- Групповое разбиение не заменяет проверку на данных другого периода или продавца.
- Следующие шаги: проверка отмеченных аномалий по первоисточнику, оценка правил
  очистки внутри кросс-валидации, сравнение с моделью на логарифме цены
  и проверка на внешних данных.
- Лицензия на код пока не выбрана. Публикация репозитория сама по себе
  не задаёт условия свободного переиспользования.
